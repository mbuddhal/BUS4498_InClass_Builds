# weekly-digest

## User inputs
The user provides the topic they want the newsletter about and any specific preferences, such as the audience, length, or sections they want included.

If an essential detail is missing, ask the user for it before creating the newsletter.

## Procedure
1. Identify the user's topic, audience, and preferences.
2. Gather the most relevant and recent information about the topic.
3. Check that the information is relevant to the newsletter and remove unnecessary details.
4. Organize the information into the newsletter sections.
5. Write the newsletter using the output format below.
6. Check the final newsletter for accuracy, clarity, and consistency.

## Output
Create a clear and easy-to-read newsletter with:
- A title
- A short introduction
- The main stories or updates
- Brief summaries for each story
- A short closing section

## Boundaries
Ask the user for clarification if the topic or intended audience is unclear.

Do not make up facts or sources, and cite where you are pulling news info from. If information cannot be verified, tell the user.
